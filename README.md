# Work Templates

Reusable templates for industrial machinery projects, vendor communication, schedules, and field preparation.

## Purpose

This repository keeps practical templates that can be reused for press installation, dismantling, relocation, RFQ, and customer communication.

## Repository Structure

| Folder | Purpose |
| --- | --- |
| `rfq/` | Vendor inquiry and quotation request templates |
| `schedules/` | Project schedule and manpower templates |
| `checklists/` | Pre-work and site readiness checklists |

## Core Principle

Write once, reuse many times. Each template should be simple, clear, and easy to adapt for Korean, Japanese, and English communication.
